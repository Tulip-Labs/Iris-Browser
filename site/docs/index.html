Getting started

Iris runs on Linux (Wayland) and Android. Both come from GitHub Releases. There are no package repositories: the old apt, dnf and zypper repositories are discontinued.

Linux (Flatpak)

Iris for Linux ships as one Flatpak bundle, Iris-x86_64.flatpak, on the WPE WebKit engine. It is a native Wayland app (no X11, no GTK).

  1. Download Iris-x86_64.flatpak from the latest release.
  2. Iris needs the GNOME 50 runtime, which Flatpak installs from Flathub. If the Flathub remote isn't set up yet: 
    flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  3. Install the bundle: 
    flatpak install --user Iris-x86_64.flatpak

The app ID is io.github.tulip_labs.Iris. On niri 26.04 and newer the blur behind the window comes on by itself; no window rule is needed. Elsewhere the window stays nearly solid.

The Chromium (CEF) build From 2.3

Beside the WPE build there is a second Flatpak, Iris (Chromium), app ID io.github.tulip_labs.Iris.Cef: the same app built on CEF 156. It installs side by side with the WPE build. It has releases of its own, tagged cef-v (for example cef-v2.4.0, titled "Iris (Chromium) 2.4.0"), with its own version number. They carry only Iris-Cef-x86_64.flatpak and its SHA256SUMS, and they are never the "latest" release, which stays the WPE build and Android. Download the bundle from the newest cef-v release and install it:

flatpak install --user Iris-Cef-x86_64.flatpak

Iris (Chromium) checks its own releases once a day and links to the new bundle when there is one; installing it the same way updates it. To build it yourself instead:

flatpak-builder --user --install --force-clean build packaging/flatpak/io.github.tulip_labs.Iris.Cef.yml

What it gives up next to the WPE build:

  • Chromium's renderer sandbox is off. It needs a setuid helper or user namespaces, and a Flatpak has neither. Renderers run inside Flatpak's sandbox only; WPE keeps its own process sandbox.
  • No H.264, H.265 or AAC. CEF's binaries ship without the proprietary codecs. VP9, AV1 and Opus play, and YouTube works.
  • More CPU for page frames, which are copied instead of shared with no copy as in WPE. Chromium composites in software by default; IRIS_CEF_GPU=1 tries the GPU.
  • Much larger. libcef.so alone is a few hundred MB.

Android

  1. Download Iris-android.apk from the latest release.
  2. Open it and let Android install it. Iris needs Android 10 or newer.

Iris for Android carries its own Chromium (Cefrium), so it runs on the same engine on every phone. It installs over earlier versions and keeps your tabs and sign-ins.

Updates

  • Linux: once a day Iris asks GitHub for the newest release and tells you when there is one. To update, download the new Iris-x86_64.flatpak and install it the same way.
  • Android: Iris checks GitHub once a day, downloads the new APK and has Android install it over itself. Updates come only from Iris's own releases, over https.

First steps

  • A new tab opens on Iris's start page From 2.3: the glass ring and one search box. Type an address, or anything else to search.
  • Your tabs come back next time you open Iris.
  • Shields are on from the first start. The first start takes a moment while the block lists are made ready.
  • Press Ctrl+K for the command palette From 2.3, which finds tabs, commands and history.
