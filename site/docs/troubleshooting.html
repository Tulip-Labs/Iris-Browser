Troubleshooting and FAQ

A site doesn't work

  • Shields: right-click the page and choose Site broken? Reload without Shields From 2.3. Or turn Shields off for the site in the Shields panel. See Shields.
  • The sandbox: sites on plain http, a bare IP address or a failing certificate open in the sandbox (orange rim), where downloads, the camera, WebRTC and pop-ups are off. That is on purpose.

The Flatpak won't install

The bundle needs the GNOME 50 runtime from Flathub. Add the Flathub remote, then install again:

flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user Iris-Cef-x86_64.flatpak

No blur behind the window

The glass shows the desktop blurred only where the compositor offers background blur through ext-background-effect-v1 (niri 26.04 and newer, and others that adopt it). Elsewhere the window stays nearly solid. This is expected.

Iris doesn't start

Iris for Linux is a Wayland app with no X11 code, so it needs a Wayland session. If it still won't start, run it from a terminal and open an issue with what it prints:

flatpak run io.github.tulip_labs.Iris.Cef

Video

  • Iris for Linux doesn't play H.264, H.265 or AAC. VP9, AV1 and Opus play, and so does YouTube.

FAQ

Is Iris on Flathub?
Not yet. Flathub asks that submissions be made by people, not AI tools, so that submission is for a person on the team to prepare. Until then, install the bundle from GitHub Releases.
What happened to the apt, dnf and zypper repositories?
They are discontinued. Use the Flatpak.
Is there a Windows or macOS version?
No. Iris is made for Linux and Android.
Does Iris put tabs to sleep?
No. Every tab stays awake, and closing a tab frees its memory.
Do I need an account?
No. Iris has no accounts and collects nothing. See Privacy.
