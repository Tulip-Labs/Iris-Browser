Contributing and license

Reporting a problem

Open an issue at github.com/Tulip-Labs/Iris-Browser/issues. Include:

  • The Iris version and the build: WPE or Chromium Flatpak, or Android.
  • Your distribution and compositor.
  • The site's address, if a site is involved, and your Shields level.

Contributing code

  1. Fork the repository and make your change on a branch.
  2. For Linux, run ./build.sh test and ./build.sh check in linux/. If you touched both engines, also run ./build.sh check-engines.
  3. Open a pull request that says what changed and why.

See Building from source to get set up.
