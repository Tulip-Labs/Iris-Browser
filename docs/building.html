Building from source

Iris for Linux is written in Odin. It talks to Wayland, EGL, OpenGL ES, HarfBuzz, fontconfig and Chromium (through CEF) directly, with no GTK. Iris for Android is Kotlin and Jetpack Compose.

git clone https://github.com/Tulip-Labs/Iris-Browser.git
cd Iris-Browser

What you need

  • Odin, dev-2026-11 or newer.
  • A C compiler to link with: clang, or gcc through ODIN_CLANG_PATH. When clang is missing, build.sh picks gcc by itself.
  • Rust (cargo): Iris's core in core/ (adblock-rust) is built first.
  • The development files of libsoup 3, HarfBuzz, fontconfig, Wayland (wayland-client, wayland-egl, wayland-cursor), xkbcommon, EGL and OpenGL ES.
  • A CEF binary distribution: CEF_DIR points at it, and its Release/ folder has libcef.so.

Arch Linux's packages have the development files.

Build

cd linux
export CEF_DIR=/path/to/cef_binary
./build.sh check-types   # type-check, no libraries needed
./build.sh test          # the tests
./build.sh check         # every C binding against the real headers
./build.sh               # a quick build to work on (no optimisation)
./build.sh release       # the optimised build, as the Flatpak ships it
./iris

./build.sh install DIR puts a release build in DIR/libexec/iris. CEF_RPATH says where libcef.so is at run time. It defaults to /app/lib/iris-cef, where the Flatpak installs it.

The Flatpak

The Flatpak downloads CEF's minimal distribution instead of building it, so it builds in minutes:

flatpak install --user flathub org.gnome.Sdk//50
flatpak-builder --user --install --force-clean build packaging/flatpak/io.github.tulip_labs.Iris.Cef.yml

Android

You need JDK 21.

cd android
./gradlew assembleRelease

Updates only install over Iris when every release is signed with the same key. CI reads the keystore from the repository's secrets: IRIS_KEYSTORE (base64), IRIS_KEYSTORE_PASSWORD and IRIS_KEY_ALIAS.

Where things are

  • linux/: Iris for Linux. build.sh, the window and Wayland client in plat/, and the app in src/: the renderer, the chrome, text, tabs, the Chromium engine and Shields.
  • android/: Iris for Android (Kotlin, Compose, Cefrium).
  • packaging/: the Flatpak manifest, desktop file and metainfo.
  • assets/icon/: the icon.

The README's How it is made describes each file and how the glass is drawn.
