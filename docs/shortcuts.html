Keyboard shortcuts

Iris for Linux has no main menu, so the keyboard does a lot of the work. This table follows the shortcuts in the README.

KeysDoes
Ctrl+T, Ctrl+Shift+TNew tab / open the last closed tab again
Ctrl+Shift+NNew private tab
Ctrl+NNew window
Ctrl+WClose tab
Ctrl+Shift+KDuplicate tab
Ctrl+MMute or unmute the tab
Ctrl+L, F6Address bar
Ctrl+KCommand palette: tabs, commands, history
Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+1…8, Ctrl+9Change tab (Ctrl+9: the last)
Alt+1…9Change workspace
Ctrl+Alt+RReader
Ctrl+Shift+SSplit View
Ctrl+Shift+CCompact mode
Alt+click a linkPeek; Enter or Ctrl+Enter makes it a tab, Esc closes it
Ctrl+R, F5, Ctrl+Shift+RReload / reload without the cache
Alt+←, Alt+→Back / forward
Alt+HomeThe start page
Ctrl+FFind in page
Ctrl+Plus, Ctrl+Minus, Ctrl+0Zoom in / out / reset
Ctrl+Shift+Y, Ctrl+JDownloads
F11Full screen
Ctrl+QQuit

Workspaces, Reader, Split View, Compact mode, Peek, the command palette, Duplicate and Mute are new in 2.3. The README still lists Alt+Home as Google AI Mode; in 2.3 it takes the tab back to Iris's start page.
