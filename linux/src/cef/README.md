# `linux/src/cef` — the CEF engine for Iris on Linux

`package cef`: the engine Iris runs on Linux when it is built with CEF.
It is the second engine beside WPE; the WPE build is the default and is
untouched by anything here.

## What it is

- `cef.odin` — the parts of CEF's C API the engine uses, hand-written
  from the CEF 156.0.32 minimal distribution headers. Every struct is
  marked `/// struct _name` so `linux/abi/check.py` holds its layout
  against the real headers.
- `cef_gen.odin` — the foreign functions, generated by
  `tools/bind.py` from `cef.txt` (`sh gen.sh`, with `CEF_DIR` set to
  the extracted CEF minimal distribution). Do not edit it by hand.
- `engine.odin` — the engine: `Browser` (one tab), init/shutdown, the
  external message pump, load/navigation, zoom, resize/hide/focus,
  mouse/key/wheel input, fire-and-forget JavaScript, find, and the
  BGRA frame the renderer paints.

## How a page reaches the screen

CEF runs windowless (off-screen rendering). The render handler's
`OnPaint` hands the engine a BGRA buffer for the view; the engine
copies it into `Browser.frame` and fires `on_frame`. The caller owns
the texture — it uploads the bytes the same way WPE's software-frame
path does (`texture_upload` in `linux/src/render.odin`). The engine
never draws anything itself.

## The tab-close guarantee

A closed tab really dies. The rules, in the code:

1. **One request context per tab.** `new_browser` creates a
   `CefRequestContext` with an empty cache path (in-memory storage), so
   the tab gets its own storage partition, which forces its own
   renderer process. Tabs never share a renderer.
2. **Close with force.** `close_browser` calls
   `CloseBrowser(force = 1)`.
3. **Drop every reference in `OnBeforeClose`.** The request context is
   released there, the browser/host pointers are cleared, `on_close`
   fires, and the engine frees the `Browser`. Nothing the engine holds
   can keep the renderer alive.
4. **Match by browser identifier, never by pointer.** CEF hands
   `OnBeforeClose` a different `cef_browser_t` wrapper than
   `OnAfterCreated`, so `browser_from_ptr` looks the tab up by
   `get_identifier`.

There is no `--process-per-tab` switch in CEF 156. If a later CEF
adds one, it does not change these rules — the context-per-tab is
what isolates storage, and the release in `OnBeforeClose` is what
lets the process die.

## Process model

CEF subprocesses re-enter the process's `main`. The caller must call
`startup` at the very top of `main` — it runs `cef_api_hash` first
(CEF 133+ requires it in every process) and `cef_execute_process`,
returning the subprocess exit code when this process is a subprocess.
Only the browser process continues to `init` and the pump.

ICU data is resolved from the libcef.so directory, not from
`resources_dir_path`: `Resources/icudtl.dat` and `*.pak` must sit
next to `libcef.so`, or `init` fails. The Flatpak layout (slice 4)
and the smoke workflow both do this copy.

## What is not here yet

- The Tab seam in the browser (slice 2): `Browser` wired behind
  `Page`, the `--engine=cef` flag, input mapping, favicon.
- JS eval **with a result** (slice 2): `execute_java_script` is
  fire-and-forget; the result round-trip is a slice-2 design item.
- Dialogs, pop-ups as related tabs, downloads, permissions, find
  results (slice 2b): pop-ups are blocked in `on_before_popup` for
  now, and the find handler is nil, so searches run but nothing
  reports the matches.
- Shields for CEF (slice 3): no WPE content rules exist in CEF, so
  the matcher and the cosmetic injection are rebuilt there.
- The Flatpak (slice 4), the tab-close check on the real build
  (slice 5), and any release (slice 6, only on Cesar's word).

## Checks

```
# Regenerate the bindings and confirm they are identical:
sh gen.sh && git diff --exit-code cef_gen.odin

# ABI check against the real headers:
python3 ../../abi/check.py \
  --headers "include/capi/cef_app_capi.h ... (see cef-smoke.yml)" \
  --cflags="-I$CEF_DIR" --import cef=. \
  cef.odin cef_gen.odin

# Pure unit tests (zoom conversion, header constants):
odin test . -extra-linker-flags:"-L$CEF_DIR/Release -Wl,-rpath,$CEF_DIR/Release -pthread"
```
